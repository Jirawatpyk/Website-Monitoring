One incident, one thread

Every message is a plain text line that starts with STATE · site, followed by a card. Escalation, the client update and recovery reply in the same thread. Daily digests and the weekly summary post to DxT Website Reports (see the Weekly summary board).
Spec note — why @mentions sit in the text line • Google Chat only notifies for <users/{id}> in the message text. A name inside a card body doesn’t notify anyone. The lock-screen preview shows the text line, so it carries the state in words. • L0 mentions only the person expected to act: the owner by day, the on-call person at night. Backup and FYI people are plain text. • An incoming webhook can’t edit a card it already posted. The first card stays as it was; each reply opens with the current state. • An ack is posted only after its 10 s Undo window closes (Arm acked 10:07:40 → posted 10:07:50).
